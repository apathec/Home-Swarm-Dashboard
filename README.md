# Home-Miner-Swarm

### Quick-glance home mining status for CYD devices

🚧 **Work in Progress — Not Yet Stable** 🚧

This project is currently under active development. Code and setup instructions will be released once a stable version is ready.

---

## 🎯 Project Goal

Develop an open-source, lightweight firmware for CYD devices that provides a real-time dashboard for monitoring and interacting with home cryptocurrency mining hardware.

Built to give home miners a simple, always-on display without needing a full dashboard or computer.

---

## ⚙️ Core Functionality

* Live hashrate monitoring
* Temperature and system stats
* Uptime and performance tracking
* Simple, clean touch-based interface

---

## 📌 Current Status

* Initial development in progress
* Hardware testing underway
* Public release coming soon

---

## 🧪 Planned Features

* Optimized UI for CYD displays
* Lightweight and responsive performance
* Easy customization and expansion
* Support for 4.3" CYD devices
* Real-time miner data integration (Bitaxe, ASICs, etc.)
