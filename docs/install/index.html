Swarm Dashboard

Bitcoin Home-Mining Swarm Monitor · ESP32

One-click installer for the Home Swarm Dashboard firmware. Plug in your ESP32 display board, click Install, and you're done — no Arduino IDE, no library juggling.

Install

Plug your ESP32 board into your computer via USB-C, then click below:

Your browser doesn't support WebSerial. Open this page in Chrome, Edge, or Opera. You can't use this page over an insecure connection. Make sure the URL starts with https://.

The installer will erase the board and flash the latest firmware.

What happens next

  1. 1Click Install above
  2. 2A browser dialog asks which USB device — pick the one that says CP210x or CH340 or USB Serial
  3. 3Wait ~60 seconds while it flashes (progress shown in real time)
  4. 4Board reboots into the WiFi setup splash. Connect your phone to SwarmDashboard-Setup (password: swarm1234) and pick your home WiFi.
  5. 5Browse to the dashboard's IP from any device on your network to add miners.

Troubleshooting

  • "No compatible device found" — your computer doesn't see the board. Try a different USB cable (some are charge-only) or install the CP210x USB driver.
  • Connect dialog is empty — board needs to be in download mode. Hold the BOOT button while clicking Install.
  • Stuck on splash after install — reset the board (unplug, replug). First boot can take up to 10 seconds.
  • Want to wipe everything and start fresh — flash again from this page; the installer erases the board first.
